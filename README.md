# Analyzing-the-Used-Car-Market-in-India

**Business Objective:**
The objective of this project is to analyze the used car market to derive actionable insights that help businesses and sellers make data-driven decisions regarding pricing and inventory management. Using Excel, the project will focus on understanding the factors affecting selling price, such as vehicle age, present price, mileage (Kms Driven), and car features like fuel type, seller type, transmission, and ownership.
